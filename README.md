# LDTS_T13_G08 - BoyGirl Game

## Game Description

This game is a **platformer adventure** where 2 players navigate through a room filled with enemies, obstacles, and collectibles. 
Players can move and interact with the environment to overcome challenges while also being able to catch more lives, all by working together.
The game features a life system, smooth controls and some obstacles to ensure an engaging experience.

This project was developed by Catarina Bastos (up202307631@up.pt). Nuno Costa (up202305503@up.pt) and Vasco Gonçalves (up202305513@up.pt).
